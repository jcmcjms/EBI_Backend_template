# Greenfield .NET 10 / C# 14 Rulesets

Rules-only package for a new backend repository.

Copy the contents into a greenfield repository before asking AI to implement the application.

Included:
- mandatory AI instructions
- Copilot instructions
- architecture rules
- C# 14 / .NET 10 rules
- performance and scalability rules
- EF Core / SQL rules
- ASP.NET API rules
- security rules
- testing rules
- change-management rules
- AI-development rules
- ADR guidance

Intentionally excluded:
- source code
- `.csproj` / `.slnx`
- `Program.cs`
- Docker
- CI
- tests
- scripts
- application configuration
